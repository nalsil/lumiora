3.2. NotiVault
3.2.1. 앱설명
- 앱 이름: NotiVault
- 한 줄 정의: 스마트폰 알림을 기기 안에 안전하게 보관·정리해 다시 찾아볼 수 있게 해주는 "알림 보관함" 앱.
- 핵심 가치: 프라이버시(모든 처리는 기기 내부, 암호화 저장), 정리(자동 분류·스팸 정리), 회고(시간순 타임머신·검색).
- 한마디로: "알림(Noti) + 금고/보관함(Vault)".

3.2.2. NotiVault 주요 서비스
1. 알림 자동 보관
• 기기에 도착하는 알림을 자동으로 수집·저장합니다.
• 본문·발신자·시각·앱·이미지(있을 경우)를 보관하며, SQLCipher로 전체 암호화 저장합니다.
• 중복 알림은 자동 제거하고, 상태바 상시 패널로 "오늘/주간/월간 저장 현황"을 확인할 수 있습니다.
2. 메시지 · 대화 보기
• 메시지 탭: 같은 제목의 알림을 대화 스레드처럼 묶어, 카카오톡식 채팅 화면으로 모아 봅니다. 안읽음 배지 표시.
• 앱별 탭: 앱 단위로 알림을 모아 봅니다.
• 메시지 아이콘을 누르면 관련 콘텐츠(원문 링크·발신 앱) 로 바로 이동합니다.
• 알림에 담긴 이미지도 말풍선·갤러리로 확인합니다.
3. 자동 분류 + 사용자 정의 분류
• 금융·결제·배송·인증(OTP)·광고·일정·업무·개인·스팸 등으로 자동 분류합니다(규칙 기반, 기기 내).
• 메시지 상단 칩으로 분류별 필터링.
• 사용자 정의 분류 추가: 이름·색을 지정해 나만의 분류를 만들고, 설정의 분류 항목 관리에서 순서 조정(드래그)·표시/숨김·추가/삭제를 직접 관리합니다.
• 특정 발신자를 원하는 분류로 고정하는 수동 분류 규칙도 지원합니다.
4. 스팸 정리
• 스팸 키워드·학습된 발신자 기준으로 자동 스팸 분류(스팸은 목록에서 숨김, 일정 기간 후 자동 삭제).
• 오분류 시 철회하면 해당 발신자는 직접 다시 설정하기 전까지 스팸으로 분류되지 않습니다(허용목록).
• 스팸 발신자 관리 화면에서 차단·허용 발신자를 앱 아이콘·이름과 함께 한눈에 보고 토글합니다.
5. 검색 (키워드 + 자연어 AI)
• 저장된 알림을 키워드로 즉시 검색합니다.
• AI 모델이 준비된 기기에서는 자연어 질문("지난주 배송 알림 보여줘")과 의미 기반 검색(RAG)을 지원합니다.
6. 인사이트 · 확인 필요
• 인사이트: 카테고리 분포, 확인 필요 비율, 앱별 알림 피로도를 시각화.
• 확인 필요: 오늘 받은 중요한(미확인) 알림만 모아 보고, 항목을 누르면 해당 메시지로 바로 이동합니다.
7. 타임머신 (시간순 회고)
• 선택한 날짜(기본 오늘)의 알림을 시간 순서대로 요약 나열합니다.
• 각 항목은 작은 앱 아이콘 + 시각 + 요약으로 표시하고, 누르면 그 메시지로 이동합니다.
• 요약은 AI 모델이 있으면 한 줄 AI 요약, 없으면 본문 일부로 표시합니다.
• 올림/내림차순 정렬을 선택할 수 있고, 선택은 유지됩니다.
8. 스마트 리마인더
• 미확인 중요 알림을 주기적으로 다시 알려주며, 알림을 누르면 확인 필요 목록으로 바로 이동합니다.
• 알림 본문에서 날짜를 추출해 일정 리마인더를 자동 예약합니다.
9. 온디바이스 AI
• 요약·자연어 검색·관련 알림 찾기에 기기 내 AI 모델을 사용합니다.
• 시스템 AICore(Gemini Nano) 또는 다운로드형 모델(Gemma) 중 자동/수동 선택. 모델이 없으면 핵심 문장 추출 방식으로 동작합니다.
• 모든 추론은 기기 안에서만 이뤄지며, 외부로 데이터가 나가지 않습니다.
10. 알림 차단
• 특정 앱의 알림 수집을 끄는 차단 화면으로, 보관 대상을 직접 관리합니다.
11. 데이터 관리
