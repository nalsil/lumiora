개인정보처리방침

시행일 2026년 6월 12일 · 최종 개정 2026년 6월 12일

루미오라(Lumiora, 이하 “회사”)는 「개인정보 보호법」 등 관련 법령을 준수하며, 정보주체의 개인정보를 보호하기 위해 본 개인정보처리방침을 수립·공개합니다. 본 방침은 회사가 제공하는 모바일 애플리케이션 NotiVault(이하 “앱”)에 적용됩니다. NotiVault는 기기에 도착하는 알림을 기기 내부에서 수집·분류·검색·요약·보관하는 로컬 우선(Local-First) 앱입니다.

핵심 원칙 — 알림의 원문(발신자·제목·본문·이미지 등)은 회사 서버나 외부로 전송되지 않으며, 모든 분류·검색·요약·AI 추론은 사용자의 기기 안에서만 수행됩니다. 다만 광고·사용통계·앱 무결성 점검·인앱결제·AI 모델 다운로드를 위해 일부 비(非)알림 정보가 아래 제5조의 제3자 서비스로 전송될 수 있습니다.

제1조 (처리하는 개인정보의 항목)

1. 기기 내부에서만 처리하는 정보 (회사 서버로 전송하지 않음)

앱은 사용자가 알림 접근 권한을 직접 허용한 경우에만 알림을 수집하여 기기 내부의 암호화 저장소(SQLCipher)에 보관합니다.

구분항목
알림 원문알림 본문·제목·발신자(앱이 표시한 발신자명)·수신 시각·출처 앱 패키지명·알림 이미지·원본 알림 payload. 본문은 수신된 원문 그대로 저장되며 인증번호·금융정보 등 민감한 내용이 포함될 수 있습니다.
추출 정보규칙 기반 추출 항목(금액·날짜·주문번호·링크 등). 인증번호(OTP)는 값을 저장하지 않고 검출 사실만 기록(****** 마스킹)합니다.
분석 메타데이터분류(카테고리)·중요도·읽음 상태·언어·중복 제거용 콘텐츠 해시.
검색용 데이터자연어(의미 기반) 검색을 위한 임베딩 벡터, 요약 캐시.
사용자 설정사용자 정의 분류·수동 분류 규칙·스팸 차단/허용 발신자·학습된 발신자·차단 앱·리마인더 설정.
로컬 식별자기기 내부에서 생성되는 임의의 설치 식별자(외부 전송 안 함).

2. 제3자 서비스를 통해 처리·전송될 수 있는 정보

목적정보비고

회사는 별도의 회원가입·로그인·계정을 두지 않으며, 이름·전화번호·이메일 등 회원 식별정보를 직접 수집하지 않습니다(문의 시 사용자가 제공하는 이메일 제외).

제2조 (개인정보의 처리 목적)

  1. 알림 보관·관리: 자동 수집·암호화 저장·중복 제거·보관 현황 제공
  2. 분류 및 검색: 자동/수동 분류, 키워드·자연어 검색
  3. 요약·인사이트·리마인더: 온디바이스 AI 요약, 카테고리/피로도 인사이트, 미확인 중요 알림 재알림
  4. 스팸 정리: 스팸 키워드·학습 발신자 기반 분류 및 허용/차단
  5. 데이터 관리권 보장: 내보내기(이동권)·보존기간 관리·삭제
  6. 서비스 품질·보안: 사용통계 기반 개선(선택), 루팅/변조 탐지
  7. 수익화(선택): 광고 노출 및 광고 제거 인앱결제

제3조 (보유·이용 기간 및 파기)

  1. 기기 내 알림 데이터는 기기에만 저장되며, 사용자의 개별/기간별/전체 삭제 시, 카테고리별 보존정책 만료 시, 또는 앱 삭제 시(암호화 키 폐기로 복호화 불가) 파기됩니다.
  2. 사용통계(선택)는 옵트아웃 시 즉시 수집 중단되며, 기존 수집분은 처리위탁사(Google)의 정책에 따릅니다.
  3. 문의 응대를 위해 제공받은 이메일은 목적 달성 후 지체 없이 파기합니다.
  4. 회사는 알림 원문에 접근하는 서버를 운영하지 않으므로 서버측 보존분이 없습니다.

제4조 (개인정보의 제3자 제공)

회사는 처리 목적 범위를 초과하여 개인정보를 제3자에게 제공하지 않습니다. 다만 ① 정보주체가 사전 동의한 경우, ② 법령에 따라 제출 의무가 있거나 수사기관이 적법 절차로 요청하는 경우는 예외입니다. 앱은 알림 원문을 외부로 전송하지 않으므로 알림 내용이 제3자에게 제공되는 일은 발생하지 않습니다.

제7조 (정보주체의 권리·행사 방법)

대부분의 권리는 앱 내 기능으로 즉시 행사할 수 있습니다.

  1. 열람·검색: 저장된 알림을 앱에서 직접 열람·검색
  2. 정정·삭제: 개별/기간별/전체 삭제(이미지 포함)
  3. 이동(내보내기): 데이터를 JSON 또는 CSV로 내보내기
  4. 처리 정지·동의 철회: 특정 앱 수집 차단, 사용통계 거부, 광고 동의 철회
  5. 활동 로그 열람: 앱 내 프라이버시 활동(감사) 로그 확인

행사·문의: 앱 설정 또는 제12조 연락처. 회사는 관련 법령이 정한 기간 내 처리합니다.

제8조 (자동 수집 장치 및 거부)

  • 광고: 기본 비개인화 지향. EEA/영국·미국 일부 주는 UMP 동의 절차. 기기 설정의 “광고 ID 재설정/삭제”로 추적 제한.
  • 사용통계: 설정 → 사용 통계 토글로 언제든 끌 수 있음(기본 켜짐).
  • 광고 제거: 인앱결제로 광고 노출 제거 가능.

제9조 (안전성 확보 조치)

  1. 저장 데이터 전체 암호화(SQLCipher) + 키는 Android Keystore(가능 시 StrongBox)로 보호.
  2. 앱 삭제·재설치 시 키 폐기 → 기존 데이터 복호화 불가.
  3. 루팅/변조 탐지 시 보관함 잠금, Play Integrity로 무결성 점검.
  4. 정식 빌드에서 민감 화면 캡처·녹화 차단.
  5. 알림 원문은 회사 서버에 두지 않으며, 설정값 등은 알림 데이터와 분리 저장.

제11조 (만 18세 미만 아동)

NotiVault는 만 18세 이상을 대상으로 합니다. 회사는 아동을 대상으로 서비스를 제공하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다. 수집 사실을 알게 되면 지체 없이 파기합니다.
